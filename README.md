Adaptive Hexapod Locomotion

Adaptive Hexapod Locomotion — экспериментальный проект по обучению шестиногого робота автономной ходьбе с использованием методов машинного обучения и reinforcement learning.

Проект использует PPO (Proximal Policy Optimization) в сочетании с эволюционным подходом для отбора и развития наиболее успешных агентов.

Project Status

The project is currently in the early stages of development.

Основные алгоритмы, физическая модель робота, архитектура нейронной сети и система вознаграждения находятся в стадии разработки и экспериментов.

На текущем этапе робот ещё не обладает полностью сформированной и стабильной походкой. Результаты могут значительно изменяться между версиями по мере тестирования новых подходов.

Проект является активной экспериментальной разработкой и будет постепенно обновляться по мере получения новых результатов.

Project Goal

Основная цель проекта — разработать систему, которая сможет самостоятельно обучить шестиногого робота устойчивой и эффективной ходьбе без заранее заданных траекторий движения ног.

В перспективе система должна научиться:

сохранять устойчивость;
координировать движение шести ног;
двигаться в заданном направлении;
поддерживать заданную скорость;
формировать эффективные походки;
адаптироваться к изменению условий окружающей среды.
Approach

В проекте исследуется комбинация нескольких подходов:

Reinforcement Learning

PPO
reward shaping
обучение взаимодействию с физической средой

Evolutionary Learning

оценка агентов;
отбор лучших результатов;
перенос параметров;
мутация и развитие следующих поколений.

Development

Проект будет развиваться постепенно.

Каждая значимая стадия разработки будет сохраняться в Git в виде отдельных версий, что позволит отслеживать изменения алгоритмов, сравнивать результаты экспериментов и возвращаться к предыдущим состояниям проекта.

Планируется регулярно добавлять новые эксперименты, улучшения алгоритмов и результаты обучения.

Versioning

Проект использует версионирование для отслеживания развития:

v0.x.x — экспериментальные версии
v1.0.0 — первая стабильная версия

Версии до 1.0.0 следует рассматривать как experimental / development releases.
